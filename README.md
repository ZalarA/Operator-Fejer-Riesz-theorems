# Mathematica Code for *Operator Fejér–Riesz Theorems with Gaps and Optimal Degree Growth*

This repository contains Mathematica/Wolfram Language code accompanying the manuscript **“Operator Fejér–Riesz Theorems with Gaps and Optimal Degree Growth”** by **Abhay Jindal and Aljaž Zalar**.

The code provides exact symbolic computations for the explicit example in the manuscript's appendix. In particular, it covers the sets

\[
K_0=[0,1]\cup[2,3], \qquad K_1=K_0\cup\{4\},
\]

and includes the rank-one matrix pencil, the degree-preserving congruence for the choice \(q=1\), scalar sums-of-squares identities, an explicit matrix certificate, and computations supporting the stated degree bounds and minimality arguments.

## Files

- **`Operator_Fejer_Riesz_Example_q1.nb`** — Mathematica notebook with annotated computations.

## Usage

Open the `.nb` file in **Wolfram Mathematica** and evaluate the cells in order. 

The code uses exact arithmetic and displays the computed polynomial and matrix expressions. It is intended to accompany the proofs in the manuscript, not replace them.

## Reference

A. Jindal and A. Zalar, *Operator Fejér–Riesz Theorems with Gaps and Optimal Degree Growth*, manuscript.
